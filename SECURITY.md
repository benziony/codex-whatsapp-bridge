# Security policy

Please do not open a public issue containing WhatsApp JIDs, hostnames, message
contents, Codex task IDs, credentials, runtime configuration, or logs. Until a
dedicated private reporting address is published, contact the repository owner
privately through GitHub.

Supported security fixes target the latest release. This project cannot secure
a compromised Hermes checkout, WhatsApp session, Codex installation, SSH
account, or macOS user account.
